# QCar Autonomous Driving

This repository is for development of QCar autonomous driving on custom tracks.

Team:
- Leader: Rafael Trinidad
- Member: Nathaniel Arifin
- Member: Tyler Bacong
- Member: Youcheng Taing
- Member: Freeman Yiu

## Functionality

The car can do the following:
 - drive autonomously on tracks
 - avoid obstacles
 - signal when turning

Future features:
- park autonomously
- establish car to car communication

## Current Development
- Sensor fusion (LiDAR+Camera)
- V2V communication
